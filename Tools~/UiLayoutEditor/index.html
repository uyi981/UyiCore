Hướng dẫn — UyiCore UI Layout Editor

Dựng layout UI kéo-thả → export .uijson → Unity dựng prefab UGUI (Image). WYSIWYG: thấy sao ra vậy ở đúng độ phân giải canvas.

1 · Thao tác

  • Move (mặc định): kéo khối = di chuyển · kéo nền = pan · lăn chuột = zoom · Fit = vừa khung
  • Draw: kéo trên 1 khối/nền để vẽ khối con bên trong nó
  • ＋ Block / ＋ Text: thêm khối Image / khối chữ vào node đang chọn. Đổi Box↔Text ở Inspector.
  • Kéo ô vuông vàng ở mép = resize · Del = xoá khối đang chọn
  • Click khối = chọn · click nền = chọn root (background)
  • Snap: kéo/resize gần mép hoặc tâm của cha / khối anh em → tự dính, hiện đường gióng đỏ. Giữ Alt tạm tắt.
  • Grid: bật lưới + đặt bước px để dính lưới. Căn trong cha (Inspector) = căn trái/giữa/phải/trên/dưới 1 click.
  • Phím tắt: Ctrl+Z undo · Ctrl+Shift+Z/Ctrl+Y redo · Ctrl+D nhân đôi · Ctrl+C/Ctrl+V copy/dán · Del xoá · ←↑↓→ nudge 1px (Shift = 10px) · V/B Move/Draw.

2 · Inspector (phải)

  • Name = tên GameObject trong prefab
  • X/Y/W/H (px) — toạ độ tương đối góc trên-trái của cha
  • Fill: bật = có Image (màu + alpha). Tắt = container rỗng (chỉ RectTransform)
  • Sprite: tên/path sprite trong Unity (optional) — resolve khi build
  • Parent: đổi cha (giữ nguyên vị trí trên màn hình)

3 · Thứ tự & lồng nhau

Layers bên trái = cây phân cấp. Con sau vẽ đè lên con trước (z-order). Dùng ↑↓ trong Layers để đổi thứ tự.

4 · Áp dụng vào Unity

1. Export → file MainMenu.uijson.

2. Trong Unity: Tools ▸ UyiCore ▸ Build UI Prefab from JSON… → chọn file → chọn nơi lưu → ra .prefab.

3. Kéo prefab vào 1 Canvas, set Canvas Scaler = Scale With Screen Size, Reference Resolution = canvasW × canvasH để khớp đúng thiết kế.

Node → GameObject + RectTransform (+ Image nếu có Fill/Sprite)
Vị trí: anchor góc trên-trái, anchoredPosition = (x, -y), sizeDelta = (w, h)
Root : stretch-fill → phủ full Canvas
  • Sprite chưa thấy trong project → log warning, vẫn tạo Image màu.
  • Toạ độ tuyệt đối — muốn responsive thì chỉnh anchor lại trong Unity.
