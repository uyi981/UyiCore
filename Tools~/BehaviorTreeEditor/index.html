Hướng dẫn — UyiCore BT Editor

Trình thiết kế Behavior Tree trực quan cho UyiCore. Quy trình: vẽ cây ở đây → export .btjson → thả vào Unity thành ScriptableObject → chạy.

1 · Thao tác

  • Kéo nền = di chuyển (pan) · lăn chuột = phóng to / thu nhỏ (zoom)
  • Bấm node ở palette (thanh trên) = tạo node giữa màn hình
  • Kéo thân node = di chuyển node
  • Kéo chấm xanh dưới node → thả lên node khác = nối cha–con
  • Kéo chấm xanh → thả chỗ trống = hiện menu chọn node → tạo + nối dây luôn
  • Click vào dây = xoá dây · phím Del = xoá node đang chọn
  • Click node = chọn & mở Inspector (bên phải)

2 · Inspector (phải)

  • Type: đổi loại node
  • Nhãn: mô tả ngắn — panel Giải thích ưu tiên dùng nhãn này (đặt "HP dưới 20%" cho dễ đọc)
  • Ref: chỉ node Action/Condition/Do — là id đăng ký trong BTRegistry bên Unity
  • Params: cặp key/value; có chip gợi ý param theo type (vd Cooldown → duration)

3 · Panel Giải thích (trái)

Tự dịch cây thành văn bản theo cấp ưu tiên ("Nếu ... thì ..."). Nút 📖 Giải thích ẩn/hiện, Copy lấy text thuần. Đặt Nhãn cho node để đọc thuần Việt.

4 · Root & thứ tự

  • Root = node không có cha (viền vàng, badge ROOT). Cây phải có đúng 1 root.
  • Thứ tự con = trái → phải theo vị trí X (số trên node). Selector/Sequence xét con theo thứ tự này.

5 · Các loại node

  • Composite: Selector (ưu tiên/OR) · Sequence (tuần tự/AND) · Parallel (song song)
  • Decorator (1 con): Inverter · Repeater · Cooldown · UntilSuccess · UntilFailure
  • Leaf: Wait · Succeed · Fail
  • Registry (cần ref): Action (trả NodeStatus) · Condition (bool) · Do (chạy rồi Success)

6 · Lưu / Mở

  • Export .btjson: Tải file hoặc Copy JSON
  • Open hoặc kéo-thả file .btjson vào canvas = mở lại để sửa
  • Tự lưu nháp vào browser (localStorage) — mở lại tab không mất

7 · Áp dụng vào Unity

Đây là phần ráp cây vào game thật.

Bước 1. Export cây → file GruntAI.btjson.

Bước 2. Thả file vào Assets/ — UyiCore tự import thành BehaviorTreeAsset (ScriptableObject). Inspector của SO hiện outline + báo lỗi nếu có.

Bước 3. Viết BTRegistry map mỗi ref trong cây → hành vi C# thật:

var reg = new BTRegistry<Enemy>()
    .Condition("HpBelow", (e,p) => e.HpPercent < p.GetFloat("threshold",0.2f))
    .Do("Flee",   e => e.Flee())
    .Do("Patrol", e => e.Patrol())
    .Action("Chase", e => e.MoveTo(e.Player.position)
                           ? NodeStatus.Success : NodeStatus.Running);

Bước 4. Compile asset → cây runtime, tick mỗi frame:

[SerializeField] BehaviorTreeAsset tree;   // kéo SO vào field này
BehaviorTree<Enemy> _bt;
void Start(){ _bt = BehaviorTreeCompiler.Compile(tree, this, reg); }
void Update(){ _bt.Tick(Time.deltaTime); }
  • Mỗi enemy Compile 1 lần → có cây state riêng.
  • Ref nào chưa đăng ký → node đó fail + log rõ tên (không crash).
  • x,y trong JSON chỉ để editor nhớ layout — Unity JsonUtility bỏ qua.
  • Đuôi .btjson riêng nên không đụng các file .json khác trong project.
